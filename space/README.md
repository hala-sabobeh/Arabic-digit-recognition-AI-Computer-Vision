# Arabic Handwritten Digit Recognition

Upload a handwritten Arabic digit image or draw one with the sketchpad. The app displays the three most likely classes.

Add the trained Keras model to `models_optimized_v2/best_model.keras`, or set `MODEL_PATH` to its location in the Space settings. Model weights are not included in this repository.
